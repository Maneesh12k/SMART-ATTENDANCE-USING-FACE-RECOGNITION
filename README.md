# Face Recognition Attendance Management System

## Project Overview

A Python-based face recognition attendance management system
developed as a final-year project.

## Features

- Secure Login
- New User Registration
- Forgot Password
- Student Management
- Face Detection
- Face Recognition
- Automatic Attendance
- Attendance Import/Export
- Attendance Delete
- Student Delete
- Face Sample Collection
- Automatic Recognition Training
- MySQL Database

## Technologies Used

- Python
- Tkinter
- OpenCV
- MySQL
- NumPy
- Pillow
- Pandas

## How to Run

1. Install Python
2. Install MySQL
3. Install required packages
4. Configure the database
5. Run START_APPLICATION.bat
